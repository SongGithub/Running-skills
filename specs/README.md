# Spec Kit feature catalogue

Feature specs live in numbered directories so requirements, plans and tasks stay grouped by change. The Spec Kit constitution and workflow are under `.specify/`.

- [`001-strava-publish-gate/spec.md`](001-strava-publish-gate/spec.md) — guarded Strava publishing with a local private policy and content-bound review.

Personal preferences, credentials and live activity copy are not feature specs and must remain in local policy files outside Git. A feature spec may define the *mechanism* for applying a policy without publishing the policy itself.
